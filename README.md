# HM Carpets - Official Website

**Pakistan's Premium Carpets, Janamaz & Mats Manufacturer**

Beautiful, fully responsive, bilingual (English + Urdu) website with dark/light mode support, built for HM Carpets.

---

## Features

- Bilingual - English + Urdu language toggle
- Dark/Light Mode - Beautiful theme switcher with persistence
- Fully Responsive - Mobile-first design, perfect on all devices
- Lightning Fast - Optimized assets, lazy loading, CDN-cached
- Premium Animations - AOS, smooth scrolling, parallax effects
- SEO Optimized - Complete meta tags, sitemap, structured data
- PWA Ready - Install as app on mobile devices
- Secure Headers - Production-grade security configuration

## Local Development

Clone the repo and run a local server:

    git clone https://github.com/YOUR_USERNAME/hmcarpets.git
    cd hmcarpets
    python3 -m http.server 8000

Then open: http://localhost:8000

## Deployment

This site is deployed on Vercel with automatic deployments from main branch.

Push to main branch and Vercel auto-deploys within seconds.
